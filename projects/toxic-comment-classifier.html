Toxic Comment Classifier

Task: Multi-Label Text Classification Architecture: Recurrent LSTM & Word Embeddings Framework: TensorFlow / Keras
Project Overview

A deep learning and natural language processing system developed using Long Short-Term Memory (LSTM) neural networks for multi-label text classification. Analyzes online discussion comments to detect multiple overlapping toxicity categories (toxic, severe toxic, obscene, threat, insult, identity hate).

01

Technology Stack

Python TensorFlow / Keras LSTM (Long Short-Term Memory) NLTK Word Tokenization & Padding Scikit-Learn Jupyter Notebook
02

Problem Statement & Constraints

!
Multi-Label Non-Exclusive Classification

A toxic comment may simultaneously contain profanity, personal insults, and identity threats, requiring independent sigmoid probability thresholds per class rather than single softmax exclusivity.

!
Informal Slang & Variable Sequence Lengths

Online comments exhibit slang, misspellings, and highly variable text lengths requiring robust tokenization, vocabulary clipping, and sequence padding.

Key Engineering Decisions

Why LSTM over standard Bag-of-Words / TF-IDF?
TF-IDF disregards syntax and word ordering, missing negation semantics (e.g., "not toxic" vs "toxic"); LSTM preserves sequence dynamics.
Why Binary Cross-Entropy loss for multi-label targets?
Binary cross-entropy treats each of the 6 category probabilities independently, enabling simultaneous positive predictions.
