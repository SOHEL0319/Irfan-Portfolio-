Weather Forecasting on Time-Series Data

Timeline: Feb 2026 – May 2026 Core: Time-Series & Feature Engineering Accuracy: 86.45% (XGBoost) | 86.36% (LSTM)
Project Overview

A machine learning time-series system developed for Bangalore historical rainfall datasets. Employs temporal lag features, rolling statistics, and seasonal trend decomposition with comparative evaluation of XGBoost (86.45% accuracy) and Long Short-Term Memory recurrent networks (86.36% accuracy) for discrete rain-day classification.

01

Technology Stack

Python Pandas NumPy Statsmodels Scikit-Learn XGBoost LSTM / TensorFlow Matplotlib Seaborn Jupyter Notebook
02

Problem Statement & Constraints

!
Non-Linear Temporal Dependencies

Weather data exhibits heavy auto-correlation and seasonal fluctuations that standard non-temporal regression algorithms fail to model accurately.

!
Monsoon Skew & Imbalanced Classes

Rainfall occurrence is concentrated during specific seasonal windows, requiring robust feature extraction and class weighting to prevent trivial dry-day majority predictions.

03

Engineering Objectives & System Goals

Temporal Feature Engineering
Construct sliding-window lag features (t-1, t-3, t-7, t-30) and rolling precipitation variance.
Seasonal Trend Decomposition
Decompose historical climate series into trend, seasonal, and residual components using Statsmodels.
Model Benchmarking
Evaluate Gradient Boosted Decision Trees against Recurrent Neural Networks on holdout test partitions.
Rain-Day Prediction Efficacy
Deliver verified high accuracy in classifying discrete precipitation events.

05

Feature Engineering Deep Dive

LAG TERMS
Multi-Order Historical Lags Generated t-1, t-2, t-3, t-7, and t-30 day lag terms to capture short-term memory and weekly periodicity.
ROLLING STATS
Moving Windows Calculated 7-day and 30-day rolling means and standard deviations to represent atmospheric volatility.
CALENDAR
Cyclical Encoding Sine and cosine transformations on day-of-year to model annual seasonality smoothly across year boundaries.
06

Model Comparative Analysis

XGBoost Gradient Boosting
Tree-based gradient boosting efficiently captured tabular interactions between engineered lag features, achieving 86.45% accuracy with fast training times.
LSTM Recurrent Neural Network
Sequential LSTM memory cells processed historical sequence tensors directly, achieving 86.36% accuracy and learning long-range temporal dependencies.

08

Key Engineering Decisions

Why frame the problem as discrete rain-day classification?
Discrete rain vs. no-rain classification provides direct actionable utility for municipal scheduling while avoiding noisy millimeter-level sensor variance.
Why compare XGBoost with LSTM?
Validates whether recurrent deep learning outperforms feature-engineered gradient boosted trees on tabular meteorological series.
