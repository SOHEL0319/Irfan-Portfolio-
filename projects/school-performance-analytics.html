School Performance Analytics Dashboard

Platform: Power BI Desktop Discipline: Data Modeling & DAX Scope: Multi-Branch Academic Reporting
Project Overview

An end-to-end school performance analytics platform built using Power BI, DAX, data modeling, and business intelligence techniques to evaluate student grades, attendance metrics, branch-level comparisons, and class performance distributions.

01

Technology Stack

Power BI DAX Power Query (M) Data Modeling (Star Schema) ETL & Data Cleaning
02

Problem Statement & Constraints

!
Fragmented Spreadsheets & Manual Reporting

School administrators track student attendance and examination marks across disconnected files, making it hard to identify at-risk students or evaluate branch-wise teacher performance.

03

Engineering Objectives

Centralized Data Model
Integrate students, branches, subjects, and test records into a unified relational schema.
Dynamic KPI Measures
Build DAX expressions for GPA calculation, attendance rates, and grade distribution percentiles.
04

Data Modeling Pipeline Flow

Academic CSVs Marks & Attendance
➔
Power Query ETL Type Transformation
➔
Star Schema Dimension & Fact Tables
➔
DAX Engine KPI Metrics
➔
Interactive UI Drill-Down Slicers
05

Core Reporting Views

Student Performance View

Individual student scorecards, examination history, subject strengths, and GPA progression charts.

Attendance & Branch Comparison

Class-level attendance heatmaps, absentee trend analysis, and comparative branch metrics.

Key Engineering Decisions

Why use dimension tables for branches and classes?
Normalized dimension tables enable cross-filtering across academic years without altering historical examination fact records.
